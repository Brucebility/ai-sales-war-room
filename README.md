# AI 销售作战室 | Sales War Room

> AI Native 产品经理实测试题 Demo — 企业级 AI Agent 雏形

## 项目简介

本 Demo 模拟一个 B2B AI 销售决策场景：销售、主管、技术三方对客户 A 是否推进产生真实冲突。AI Agent 基于统一事实知识库，执行风险推演、冲突识别、证据推理，最终输出可分派的决策行动。

## 目录结构

```
ai-sales-war-room/
├── index.html          # HTML 结构（6大模块 + 流程图）
├── css/
│   └── style.css       # 全部样式（深色主题）
├── js/
│   ├── data.js         # Mock 数据层（客户/案例/资源/KPI/行动项）
│   └── app.js          # 应用逻辑（时钟/事实源切换/证据跳转/角色切换/任务流转）
└── README.md           # 本文档
```

## 模块划分

| 模块 | 名称 | 满足要求 |
|------|------|---------|
| Module 0 | Agent 工作流程总览（SVG 流程图） | 全局流程可视化 |
| Module 1 | 商机总览工作台 | 聚焦客户 A 商机 |
| Module 2 | 冲突共识面板【核心】 | 要求1：呈现冲突 |
| Module 3 | AI 智能研判模块 | 要求2：证据链 + 要求5：Agent雏形 |
| Module 4 | 角色视图切换器 | 要求3：不同角色看到不同信息 |
| Module 5 | 决策与下一步行动 | 要求4：明确决策 + 任务流转 |
| Module 6 | Agent 事实知识库（侧边栏） | Agent 底层事实源 |

## 运行方式

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建工具。

## 交互功能

- **证据回溯**：点击证据链中的来源链接，自动展开左侧事实源并高亮对应数据项
- **角色切换**：点击顶部 4 个视角按钮，其他角色卡片变暗，关注焦点动态切换
- **任务流转**：在行动项中选择分派人 → 点击"推进"按钮，状态从待分派→已分派→进行中→已完成
- **事实源展开/折叠**：点击左侧栏各数据源标题可展开/收起
- **立场卡片展开/折叠**：点击冲突共识面板中的角色卡片可展开/收起

## 技术栈

- 纯 HTML + CSS + JavaScript（零依赖）
- SVG 内联流程图
- CSS 变量主题系统（深色主题）
- 响应式布局（移动端适配）
